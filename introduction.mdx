# Welcome to Kairo

Kairo is the intelligence layer for the Riwi bootcamp ecosystem. It combines academic performance data from Moodle with soft skills assessments to generate adaptive, personalized 4-week growth plans for every coder — and gives Team Leaders the analytics they need to intervene before students fall behind.

## What Kairo does

Riwi's 11-month bootcamp moves fast. Kairo ensures no coder is left behind by analyzing two key dimensions of every student:

- **Technical performance** — Moodle scores, struggling topics, module progress
- **Soft skills profile** — Autonomy, time management, problem solving, communication, teamwork, and learning style

From these inputs, the AI microservice generates 6 priority-ranked learning cards per coder: 2 high-priority, 2 medium, and 2 low — each with daily activities tailored to the individual's learning style.

## Key features

- **Adaptive learning plans** — 6 cards per coder, generated by Groq LLM with LangChain orchestration, ranked by priority
- **Soft skills integration** — A 20-question onboarding quiz maps each coder's learning style and interpersonal skills
- **Risk detection** — Automated flags when `average_score < 70` or `autonomy ≤ 2`, giving TLs early warning
- **AI chat trainer** — On-demand conversational assistant using the same LLM stack
- **Resource search** — Semantic search over curated materials using `all-MiniLM-L6-v2` embeddings (384 dimensions)
- **Real-time notifications** — Supabase Realtime pushes TL feedback to coders instantly
- **Social login** — GitHub OAuth and Google OAuth for frictionless authentication
- **Exercise generation** — AI-generated coding exercises with automated submission evaluation

## Technology stack

| Layer | Technology |
|-------|-----------|
| Frontend | HTML5 / CSS3 / Vanilla JS / Bootstrap 5 |
| Backend API | Node.js 20 + Express.js 5 |
| AI Microservice | Python 3.12 + FastAPI + LangChain |
| LLM | Groq (Llama-3.3-70B / Qwen2.5-7B-Instruct) |
| Database | PostgreSQL 14+ via Supabase |
| Auth | Passport.js + GitHub OAuth + Google OAuth |
| Session store | connect-pg-simple (PostgreSQL sessions) |
| Embeddings | all-MiniLM-L6-v2 (384d) |
