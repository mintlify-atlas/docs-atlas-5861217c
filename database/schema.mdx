---

All tables are defined in `schema.sql` and run on PostgreSQL 14+ (Supabase). Every table has RLS enabled — see [Row Level Security](/database/rls-policies) for the access rules that apply to each one.

<Tip>
  Foreign keys use `ON DELETE CASCADE` by default, so deleting a user
  automatically removes all of their dependent records.
</Tip>

---

## users

All platform users — both coders and Team Leaders.

| Column       | Type           | Constraints                      | Description                                           |
| ------------ | -------------- | -------------------------------- | ----------------------------------------------------- |
| `id`         | `SERIAL`       | PRIMARY KEY                      | Auto-incrementing identifier                          |
| `email`      | `VARCHAR(100)` | UNIQUE, NOT NULL                 | Login email address                                   |
| `password`   | `VARCHAR(255)` | NOT NULL                         | Hashed password                                       |
| `full_name`  | `VARCHAR(150)` | NOT NULL                         | Display name                                          |
| `role`       | `role_enum`    | NOT NULL                         | `coder` or `tl`                                       |
| `clan_id`    | `VARCHAR(50)`  | —                                | Clan name: `Turing`, `Tesla`, or `McCarthy`           |
| `first_login`| `BOOLEAN`      | DEFAULT `true`                   | `true` until the coder completes onboarding           |
| `created_at` | `TIMESTAMP`    | DEFAULT `CURRENT_TIMESTAMP`      | Account creation timestamp                            |

**Indexes:** `idx_users_email` (email), `idx_users_role` (role), `idx_users_clan_id` (clan_id)

## soft_skills_assessment

1:1 with `users`. Stores results from the 20-question onboarding quiz taken by each coder.

| Column            | Type                  | Constraints                                        | Description                                               |
| ----------------- | --------------------- | -------------------------------------------------- | --------------------------------------------------------- |
| `id`              | `SERIAL`              | PRIMARY KEY                                        | Auto-incrementing identifier                              |
| `coder_id`        | `INT`                 | NOT NULL, UNIQUE, FK → `users(id)` ON DELETE CASCADE | The coder this assessment belongs to                    |
| `autonomy`        | `INT`                 | NOT NULL, CHECK (1–5)                              | Self-directed learning score                              |
| `time_management` | `INT`                 | NOT NULL, CHECK (1–5)                              | Time management skill score                               |
| `problem_solving` | `INT`                 | NOT NULL, CHECK (1–5)                              | Problem-solving skill score                               |
| `communication`   | `INT`                 | NOT NULL, CHECK (1–5)                              | Communication skill score                                 |
| `teamwork`        | `INT`                 | NOT NULL, CHECK (1–5)                              | Teamwork skill score                                      |
| `learning_style`  | `learning_style_enum` | NOT NULL                                           | Dominant style: `visual`, `auditory`, `kinesthetic`, `mixed` |
| `raw_answers`     | `JSONB`               | —                                                  | Full answer array `[{questionId, optionId, score}]` for audit |
| `assessed_at`     | `TIMESTAMP`           | DEFAULT `CURRENT_TIMESTAMP`                        | When the quiz was submitted                               |

**Indexes:** `idx_soft_skills_coder` (coder_id)

## moodle_progress

Academic scores and week-by-week progress for each coder per module, synced from Moodle.

| Column             | Type             | Constraints                                         | Description                                          |
| ------------------ | ---------------- | --------------------------------------------------- | ---------------------------------------------------- |
| `id`               | `SERIAL`         | PRIMARY KEY                                         | Auto-incrementing identifier                         |
| `coder_id`         | `INT`            | NOT NULL, FK → `users(id)` ON DELETE CASCADE        | The coder                                            |
| `module_id`        | `INT`            | NOT NULL, FK → `modules(id)` ON DELETE CASCADE      | The module                                           |
| `current_week`     | `INT`            | NOT NULL                                            | Current week number in the module                    |
| `weeks_completed`  | `JSONB`          | DEFAULT `'[]'`                                      | Array of completed week numbers                      |
| `struggling_topics`| `TEXT[]`         | DEFAULT `'{}'`                                      | Topic names the coder flagged as difficult           |
| `average_score`    | `DECIMAL(5,2)`   | DEFAULT `0`                                         | Current overall score in the module                  |

**Unique constraint:** `(coder_id, module_id)` — one record per coder per module.

**Indexes:** `idx_moodle_coder` (coder_id), `idx_moodle_score` (average_score)

## Views

### v_coder_dashboard

A denormalized summary of each coder's progress, used directly by the coder dashboard.

```sql
CREATE VIEW v_coder_dashboard AS
SELECT 
  u.id,
  u.email,
  u.full_name,
  u.clan_id,
  ssa.autonomy,
  ssa.time_management,
  ssa.learning_style,
  m.name AS module_name,
  mp.current_week,
  mp.average_score,
  COUNT(DISTINCT pa.id) AS total_activities,
  SUM(CASE WHEN ap.completed = TRUE THEN 1 ELSE 0 END) AS completed_activities,
  ROUND((SUM(CASE WHEN ap.completed = TRUE THEN 1 ELSE 0 END)::NUMERIC / 
         NULLIF(COUNT(DISTINCT pa.id), 0)) * 100, 2) AS completion_percentage
FROM users u
LEFT JOIN soft_skills_assessment ssa ON u.id = ssa.coder_id
LEFT JOIN moodle_progress mp ON u.id = mp.coder_id
LEFT JOIN modules m ON mp.module_id = m.id
LEFT JOIN complementary_plans cp ON u.id = cp.coder_id AND cp.is_active = TRUE
LEFT JOIN plan_activities pa ON cp.id = pa.plan_id
LEFT JOIN activity_progress ap ON pa.id = ap.activity_id AND ap.coder_id = u.id
WHERE u.role = 'coder'
GROUP BY u.id, u.email, u.full_name, u.clan_id, ssa.autonomy, ssa.time_management, 
         ssa.learning_style, m.name, mp.current_week, mp.average_score;
```

### v_coder_risk_analysis

Calculates a risk level for each coder based on autonomy score and Moodle average. Used by Team Leaders to monitor their clan.

```sql
CREATE VIEW v_coder_risk_analysis AS
SELECT 
  u.id,
  u.email,
  u.full_name,
  ssa.autonomy,
  ssa.time_management,
  mp.average_score,
  COALESCE(rf.risk_level, 'low'::risk_level_enum) AS current_risk_level,
  CASE 
    WHEN ssa.autonomy <= 2 AND mp.average_score < 70 THEN 'high'::risk_level_enum
    WHEN ssa.autonomy <= 2 OR mp.average_score < 70 THEN 'medium'::risk_level_enum
    ELSE 'low'::risk_level_enum
  END AS calculated_risk_level,
  COUNT(DISTINCT pa.id) AS total_activities,
  SUM(CASE WHEN ap.completed = TRUE THEN 1 ELSE 0 END) AS completed_activities
FROM users u
LEFT JOIN soft_skills_assessment ssa ON u.id = ssa.coder_id
LEFT JOIN moodle_progress mp ON u.id = mp.coder_id
LEFT JOIN risk_flags rf ON u.id = rf.coder_id AND rf.resolved = FALSE
LEFT JOIN complementary_plans cp ON u.id = cp.coder_id AND cp.is_active = TRUE
LEFT JOIN plan_activities pa ON cp.id = pa.plan_id
LEFT JOIN activity_progress ap ON pa.id = ap.activity_id AND ap.coder_id = u.id
WHERE u.role = 'coder'
GROUP BY u.id, u.email, u.full_name, ssa.autonomy, ssa.time_management, 
         mp.average_score, rf.risk_level;
```

<Note>
  `calculated_risk_level` is derived on the fly. `current_risk_level` reflects
  the latest unresolved flag in `risk_flags`, defaulting to `low` when no flag
  exists.
</Note>
