## Dashboard

**`GET /api/tl/dashboard`**

Returns a full overview of the TL's clan: coder list with progress and soft skills, clan statistics, and soft skills averages.

### Response

<ResponseField name="tl" type="object">
  <Expandable title="properties">
    <ResponseField name="fullName" type="string">TL's display name.</ResponseField>
    <ResponseField name="clanId" type="string">Clan identifier.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="coders" type="object[]">
  All active coders in the TL's clan. Each item includes `id`, `fullName`, `email`, `kairoScore`, `averageScore`, `currentWeek`, soft skill scores, and `riskLevel`.
</ResponseField>

<ResponseField name="overview" type="object">
  <Expandable title="properties">
    <ResponseField name="totalCoders" type="number">Total coders in the clan.</ResponseField>
    <ResponseField name="completedOnboarding" type="number">Coders who have finished onboarding.</ResponseField>
    <ResponseField name="pendingOnboarding" type="number">Coders still on first login.</ResponseField>
    <ResponseField name="highRiskCoders" type="number">Coders with `high` or `critical` risk flags.</ResponseField>
    <ResponseField name="clanAvgScore" type="number">Mean Kairo score across the clan.</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="softSkillsAverage" type="object">
  Clan averages for `autonomy`, `time_management`, `problem_solving`, `communication`, and `teamwork` (only coders with completed diagnostics are included).
</ResponseField>

<CodeGroup>

```bash cURL
curl http://localhost:3000/api/tl/dashboard \
  -b cookies.txt
```

</CodeGroup>

## Submit feedback

**`POST /api/tl/feedback`**

Creates a feedback record for a coder and dispatches a real-time notification to them.

### Request body

<ParamField body="coderId" type="number" required>
  ID of the coder receiving the feedback.
</ParamField>

<ParamField body="feedbackText" type="string" required>
  Feedback message. Input is sanitized server-side.
</ParamField>

<ParamField body="feedbackType" type="string" required>
  Category of feedback (e.g. `positive`, `constructive`, `urgent`). Input is sanitized server-side.
</ParamField>

### Response

<ResponseField name="success" type="boolean">`true` on success.</ResponseField>
<ResponseField name="message" type="string">Confirmation.</ResponseField>
<ResponseField name="data" type="object">The newly created feedback record.</ResponseField>

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3000/api/tl/feedback \
  -H "Content-Type: application/json" \
  -b cookies.txt \
  -d '{
    "coderId": 7,
    "feedbackText": "Great work on the recursion exercises this week.",
    "feedbackType": "positive"
  }'
```

</CodeGroup>

**201 Created**

```json
{
  "success": true,
  "message": "Feedback registered",
  "data": {
    "id": 88,
    "coder_id": 7,
    "tl_id": 3,
    "feedback_text": "Great work on the recursion exercises this week.",
    "feedback_type": "positive",
    "created_at": "2026-03-15T12:00:00.000Z"
  }
}
```

**400 Bad Request** — one or more required fields missing.

## List submissions

**`GET /api/tl/submissions`**

Returns up to 50 recent exercise submissions from coders in the TL's clan, ordered by submission time descending.

### Response

<ResponseField name="submissions" type="object[]">
  Each item includes `id`, `code_submitted`, `submitted_at`, `tl_feedback_text`, `reviewed_at`, `exercise_title`, `language`, `difficulty`, `topic`, `coder_name`, `coder_id`, and `plan_id`.
</ResponseField>

<CodeGroup>

```bash cURL
curl http://localhost:3000/api/tl/submissions \
  -b cookies.txt
```

</CodeGroup>

**400 Bad Request** — TL has no clan assigned.

## Review submission

**`POST /api/tl/submissions/:id/review`**

Adds TL feedback to a coder's exercise submission. Awards bonus Kairo points to the coder and sends them a real-time notification.

### Path parameters

<ParamField path="id" type="number" required>
  Submission ID to review.
</ParamField>

### Request body

<ParamField body="feedbackText" type="string" required>
  Review comment. Must be a non-empty string.
</ParamField>

### Response

<ResponseField name="success" type="boolean">`true` on success.</ResponseField>
<ResponseField name="submission" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="number">Submission ID.</ResponseField>
    <ResponseField name="tl_feedback_text" type="string">Saved feedback text.</ResponseField>
    <ResponseField name="reviewed_at" type="string">ISO 8601 review timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3000/api/tl/submissions/201/review \
  -H "Content-Type: application/json" \
  -b cookies.txt \
  -d '{"feedbackText": "Good approach, but consider edge cases for empty arrays."}'
```

</CodeGroup>

**400 Bad Request** — `feedbackText` is missing or blank.

**404 Not Found** — submission not found or belongs to a coder outside this TL's clan.

## Coder score history

**`GET /api/tl/coder/:id/score`**

Returns the Kairo point history for a specific coder (last 20 events) along with their current score.

### Path parameters

<ParamField path="id" type="number" required>
  Coder user ID.
</ParamField>

### Response

<ResponseField name="coderId" type="number">Requested coder ID.</ResponseField>
<ResponseField name="currentScore" type="number">Current Kairo score.</ResponseField>
<ResponseField name="history" type="object[]">
  <Expandable title="item properties">
    <ResponseField name="label" type="string">Human-readable event label (e.g. `Día completado`, `TL aprobó solución`).</ResponseField>
    <ResponseField name="points" type="number">Points awarded (positive) or deducted (negative).</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601 timestamp.</ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>

```bash cURL
curl http://localhost:3000/api/tl/coder/7/score \
  -b cookies.txt
```

</CodeGroup>

## Score ranking

**`GET /api/tl/ranking`**

Returns the Kairo score ranking for the TL's clan and the global top-10 ranking.

### Response

<ResponseField name="clan" type="string">TL's clan identifier.</ResponseField>

<ResponseField name="clanRanking" type="object[]">
  All active coders in the clan ordered by `kairo_score` descending, with a `rank` field.
</ResponseField>

<ResponseField name="globalRanking" type="object[]">
  Top 10 active coders globally, ordered by `kairo_score` descending.
</ResponseField>

<CodeGroup>

```bash cURL
curl http://localhost:3000/api/tl/ranking \
  -b cookies.txt
```

</CodeGroup>

## Upload resource

**`POST /api/tl/resource/upload`**

Uploads a PDF resource (max 20 MB) via `multipart/form-data`. Only `application/pdf` files are accepted.

### Request body (multipart)

<ParamField body="file" type="file" required>
  PDF file to upload. Must be `application/pdf`; other MIME types are rejected.
</ParamField>

<CodeGroup>

```bash cURL
curl -X POST http://localhost:3000/api/tl/resource/upload \
  -b cookies.txt \
  -F "file=@/path/to/guide.pdf"
```

</CodeGroup>
