---
title: "Quickstart"
description: "Get Kairo running locally end-to-end in under ten minutes."
---

<Note>
Kairo requires **both** backend services running simultaneously. The Node.js gateway orchestrates all business logic while the Python service handles AI inference. Starting only one will result in errors on AI-dependent features.
</Note>

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/Riwi-Project-C6/Learning-Platform.git
    cd Learning-Platform
    ```
  </Step>

  <Step title="Configure backend-node environment">
    Create `backend-node/.env` with the following variables:

    ```env
    # SERVER CONFIGURATION
    PORT=3000
    NODE_ENV=development

    # SECURITY & SESSIONS
    SESSION_SECRET=your_session_secret

    # DATABASE (POSTGRESQL - SUPABASE)
    DB_HOST=your_host
    DB_PORT=5432
    DB_NAME=your_name
    DB_USER=postgres.your_user
    DB_PASSWORD=your_password
    DATABASE_URL=your_database_url

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_ANON_KEY=your_anon_key

    # FRONTEND CONNECTION
    FRONTEND_URL=http://127.0.0.1:5500/frontend

    # PYTHON CONNECTION
    PYTHON_API_URL=http://localhost:8000

    # SOCIAL AUTH - GITHUB
    GITHUB_CLIENT_ID=your_client
    GITHUB_CLIENT_SECRET=your_client_secret

    # SOCIAL AUTH - GOOGLE
    GOOGLE_CLIENT_ID=your_client
    GOOGLE_CLIENT_SECRET=your_client_secret

    # AUTHENTICATION SMTP
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=465
    SMTP_SECURE=true
    SMTP_USER=your_email
    SMTP_PASS=your_app_password
    SMTP_FROM="Kairo <your_email>"

    # API KEY AI
    RIWI_IA_KEY=your_ia_key
    ```
  </Step>

  <Step title="Configure backend-python environment">
    Create `backend-python/.env` with the following variables:

    ```env
    # PYTHON CONFIGURATION
    PORT=8000
    ENV=development

    # OPENAI-COMPATIBLE API (Groq)
    OPENAI_API_KEY=your_api_key

    # MODEL IA
    MODEL_NAME=llama-3.3-70b-versatile

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_SERVICE_KEY=your_service_key

    # BACKEND NODE PORT
    NODE_URL=http://localhost:3000

    # FRONTEND PORT
    FRONTEND_URL=http://localhost:5500
    ```
  </Step>

  <Step title="Start the Node.js gateway (Terminal A)">
    <CodeGroup>

    ```bash Linux / macOS
    cd backend-node
    npm install
    npm run dev
    ```

    ```powershell Windows
    cd backend-node
    npm install
    npm run dev
    ```

    </CodeGroup>

    **Verification:** Wait for the following output before proceeding:

    ```
    ------------------------------------------------------------
    🚀 KAIRO API GATEWAY STARTED SUCCESSFULLY
    ------------------------------------------------------------
    📡 URL      : http://localhost:3000
    ```
  </Step>

  <Step title="Start the Python AI service (Terminal B)">
    <CodeGroup>

    ```bash Linux
    cd backend-python
    python3 -m venv env
    source env/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    ```bash macOS
    cd backend-python
    python3 -m venv env
    source env/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    ```powershell Windows
    cd backend-python
    python -m venv env
    env\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    </CodeGroup>

    **Verification:** Look for both of these log lines:

    ```
    INFO:     Supabase client initialized
    INFO:     Uvicorn running on http://0.0.0.0:8000
    ```
  </Step>

  <Step title="Open the frontend (Terminal C)">
    The recommended approach is the VS Code **Live Server** extension, which serves on port 5500 automatically.

    Alternatively, use `npx serve`:

    ```bash
    npx serve frontend -p 5500
    ```

    Open [http://127.0.0.1:5500/frontend](http://127.0.0.1:5500/frontend) in your browser.
  </Step>
</Steps>

## Verify the full stack

With all three terminals running, confirm each service is healthy:

```bash
# Node.js gateway health
curl http://localhost:3000/api/health

# Python AI engine health
curl http://localhost:8000/health
```

Both endpoints should return a `status: active` / `status: online` JSON response.
